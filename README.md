# Hoja de vida · Dilan Fabián Rojas Pérez

Sitio web personal con mi hoja de vida: experiencia, formación, proyectos y contacto.

Hecho con HTML, CSS y JavaScript, sin librerías, y publicado con GitHub Pages.

## Estructura

| Archivo | Contenido |
|---|---|
| `index.html` | Inicio y perfil profesional |
| `experiencia.html` | Experiencia laboral |
| `formacion.html` | Formación, habilidades, certificaciones e idiomas |
| `proyectos.html` | Proyectos destacados |
| `contacto.html` | Contacto y formulario (método GET) |
| `gracias.html` | Página que recibe los datos del formulario |
| `css/estilos.css` | Estilos de todo el sitio |
| `js/main.js` | Menú en celular, tema oscuro y lectura del formulario |
| `img/` | Ilustraciones SVG |
